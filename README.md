# Enerlytix Technologies, LLC — Website

Responsive static website for **Enerlytix Technologies, LLC**, featuring the **IESST Lab — Intelligent Energy** and the tagline **“Intelligence for a Sustainable Energy Future.”**

## Project structure

```text
enerlytix-website/
├── index.html
├── README.md
└── assets/
    ├── favicon.svg
    ├── css/
    │   └── styles.css
    ├── js/
    │   └── main.js
    └── images/
        └── enerlytix-logo.svg
```

## Publish with GitHub Pages

1. Create a GitHub repository for the website.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. Open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to finish and open the URL shown in the Pages settings.

For a project site, the URL is typically `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`. For a user/organisation site, use the special repository named `YOUR-USERNAME.github.io`.

## Before publishing

- Replace `YOUR-EMAIL@example.com` in `index.html` with your official contact email address.
- If you have the final high-resolution Enerlytix logo, add it as `assets/images/enerlytix-logo.png`. The page automatically falls back to the included SVG mark.
- Update the repository's social preview image if you later add one.

## Notes

- Static HTML, CSS and JavaScript; no build step or server required.
- The contact link opens the visitor's default email application. This is not a backend contact form.
- Google Fonts are optional remote fonts; system sans-serif fallbacks are defined.
